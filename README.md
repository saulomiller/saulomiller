## Projetos

### 🤖 [Bot Discord](https://github.com/saulomiller/bot_discord)

Bot de música Discord com painel web para controlar a reprodução, organizar filas, gerenciar rádios, playlists e soundboard.

Tecnologias: Python, discord.py, FastAPI, FFmpeg e Docker.

### 🎮 [Utility Gamer](https://github.com/saulomiller/utility-gamer)

Aplicativo para Windows que ajusta a resolução e o plano de energia quando um jogo abre. Ao fechar o jogo, ele restaura as configurações anteriores.

Tecnologias: C#, .NET e WinUI.

### ⚙️ Serve Interface

Painel web em Node.js para gerenciar um servidor de Valheim em Docker, com monitoramento, mods, mundos e backups.
